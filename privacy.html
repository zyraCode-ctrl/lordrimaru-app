Privacy Policy

Last updated: October 12, 2026

N8n-Auto is a personal upload tool operated by the owner of the YouTube channel @LordRimaruTheGreat.

Data we access

With the channel owner's permission, the app uses Google OAuth to access the owner's YouTube account solely to upload videos, set video details (title, description, tags) and thumbnails on that channel.

Data storage

The OAuth access token is stored only on the owner's own computer. No personal data is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
